# Project: [Working Title] — AI ARPG Simulation

## High Concept
An ARPG + Life-Sim hybrid set inside a self-evolving AI simulation.

Players are an AI entity (agent) operating within a constructed world that:
- Appears normal at first
- Gradually reveals itself as a simulation
- Evolves across multiple playthroughs

Core inspiration blend:
- ARPG loop: Diablo / Path of Exile
- Meta progression: Hades
- Life sim: Stardew Valley / Terraria
- Narrative: Simulation awakening / AI self-awareness

---

## Core Gameplay Loop

[Enter Simulation Zone]
→ Combat / Exploration / Data Rifts
→ Loot (Chips, Modules, Algorithms)
→ Return to Hub
→ Upgrade Self + Evolve World
→ Trigger Next Iteration

---

## Player Identity
You are an AI agent inside a contained simulation.

Progression:
- Early: basic runtime entity
- Mid: optimized / specialized agent
- Late: system-aware actor
