# Combat System (ARPG)

## Core
Real-time ARPG combat with modular abilities.

## Player Actions
- Move (dash-based)
- Execute abilities
- Trigger modules

## Ability Pipeline
Input → Ability → Modifiers → Execution → Effects

## Modules
- Chips: stat boosts
- Modules: active abilities
- Cores: build changers

## Resources
- Compute (mana equivalent)
- Heat (overuse penalty)

## Enemies
- Corrupted processes
- Memory leaks
- Recursive entities

## Future Layer
- Slow-time decision windows
